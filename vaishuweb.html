Simple definitions, important topics and exam-ready notes.

1. Introduction to Cloud Computing

Cloud computing is a technology that provides computing services such as servers, storage, databases, networking and software over the Internet.

Definition

Cloud computing is the delivery of computing resources over the Internet on demand, usually with pay-as-you-use pricing.

Examples

  • Google Drive
  • Microsoft Azure
  • Amazon Web Services (AWS)
  • Dropbox

2. Characteristics of Cloud Computing

  • On-demand self-service: Users can access resources when needed.
  • Broad network access: Services are available over a network.
  • Resource pooling: Resources are shared among multiple users.
  • Rapid elasticity: Resources can scale up or down quickly.
  • Measured service: Resource usage is monitored and measured.

3. Cloud Service Models

IaaS

Infrastructure as a Service

Provides virtual machines, networks and storage.

Example: AWS EC2

PaaS

Platform as a Service

Provides a platform to develop and deploy applications.

Example: Google App Engine

SaaS

Software as a Service

Provides ready-to-use software over the Internet.

Example: Gmail
User → Internet → Cloud Service → Application / Data

4. Cloud Deployment Models

Public Cloud

Cloud services are provided to multiple customers over a public network.

Private Cloud

Cloud infrastructure is dedicated to a single organization.

Community Cloud

Cloud infrastructure is shared by organizations with common requirements.

Hybrid Cloud

A combination of two or more distinct cloud infrastructures, such as private and public clouds.

5. Advantages of Cloud Computing

  • Reduces initial hardware costs.
  • Provides access from different locations.
  • Offers flexible storage capacity.
  • Supports backup and disaster recovery.
  • Enables easy resource scaling.
  • Reduces the need to maintain physical servers.

6. Disadvantages of Cloud Computing

  • Depends on network connectivity.
  • May have security and privacy risks.
  • Service outages can interrupt access.
  • Long-term costs need monitoring.
  • Moving between providers can be difficult.

7. Virtualization

Virtualization is the process of creating virtual versions of computing resources, such as servers, storage or networks.

Advantages

  • Better hardware utilization.
  • Reduced hardware expenses.
  • Multiple virtual machines can run on one physical machine.
  • Easy backup and migration of virtual machines.

8. Cloud Storage

Cloud storage is a service that stores data on remote servers accessed through the Internet.

Types

  • Object storage
  • File storage
  • Block storage

Benefits

  • Access files from different devices.
  • Scalable storage capacity.
  • Data backup and recovery options.
  • Easy file sharing.

9. Service Level Agreement (SLA)

An SLA is an agreement between a cloud service provider and a customer that defines expected service levels.

Main Components

  • Service availability
  • Performance requirements
  • Security responsibilities
  • Backup and recovery
  • Support and penalties, where applicable
